# Profile README — how to activate it

1. On GitHub, create a **new public repository** named exactly the same as your username (for example `ljrashokeng`).
2. GitHub shows a note: "You found a secret!" — that confirms it will appear on your profile.
3. Upload `README.md` from this folder (or add the folder in GitHub Desktop and publish).
4. Replace every `[CONFIRM]` item, then commit.

Tip: pin your public repositories (Profile → Customize your pins) so visitors see your best work first.
